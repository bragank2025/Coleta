# NK HUB Coleta Mobile

Aplicativo mobile para conferência de coleta de transportadoras.

## Funcionalidades

- leitura pela câmera traseira;
- detecção de pedido e chave de NF-e;
- pedido gravado mesmo quando a chave da NF-e não for lida;
- detecção de até dois códigos;
- zoom automático e controle manual;
- foco contínuo e flash quando suportados pelo aparelho;
- alerta sonoro;
- digitação manual como alternativa;
- persistência local da coleta no aparelho.

Os dados ficam armazenados no navegador do próprio dispositivo.
